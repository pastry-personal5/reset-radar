# Reset Radar

Reset Radar monitors AI-service usage and reset times across your MacBook, iPhone, and Apple Watch.

*See what’s left. Know when it resets.*

The product is planned for personal use across the owner's Apple devices. A Mac collector automatically reads derived coding-allowance state from installed first-party Codex and Claude Code tools; iPhone and Apple Watch present percentage used, reset times, freshness, and platform-appropriate glanceable surfaces. An owner-operated Cloudflare relay is conditionally approved as the encrypted store-and-forward transport, subject to its synthetic-data architecture spike. The Apple apps are signed with a free Apple account and installed for personal use, with no App Store or TestFlight distribution planned. See the [product behavior](docs/product-behavior.md), [owner decisions](docs/phase-1/owner-decisions.md), [automatic acquisition research](docs/research/phase-1/automatic-usage-acquisition.md), [Cloudflare synchronization research](docs/research/phase-1/cloudflare-synchronization.md), and [sideloading research](docs/research/phase-1/personal-use-sideloading.md).
